مشروع Kodular IDE — رسائل المحاسب الذكي v0.5

الملف الأساسي للاستيراد: SmartAccountSMS_Kodular_IDE_v0.5.aia

طريقة الاستخدام:
1) افتح Kodular Creator.
2) من Projects اختر Import project (.aia) from my computer.
3) اختر ملف .aia المرفق.
4) افتح Screen1؛ يحتوي WebViewer1 مضبوطًا لفتح assets/index.html.
5) استخدم Build لإنشاء APK.

ملاحظات مهمة:
- المشروع يضم واجهة HTML الحالية داخل assets/index.html.
- بعض خصائص استيراد SQLite من WebViewer قد تختلف حسب نسخة Android/WebView. اختبرها على الهاتف.
- إرسال SMS تلقائيًا مباشرة يتطلب إضافة صلاحيات/مكوّن Android أصلي مناسب؛ هذا المشروع يفتح تطبيق الرسائل إذا لم يتوفر جسر أصلي.
- واتساب يحتاج تأكيد الإرسال داخل واتساب.
- إن رفض Kodular اسم المشروع/المسار، استورد ملف AIA ثم احفظ نسخة باسم جديد من داخل Kodular.
